# Iris Flower Classification

A small supervised machine-learning classification project using the Iris dataset included with scikit-learn.

## Run it

From the repository root:

```bash
pip install -r requirements.txt
python projects/iris-flower-classification/iris_classification.py
```

## What it demonstrates
- Loading a built-in dataset
- Splitting data into training and test sets
- Scaling numeric features with a pipeline
- Training Logistic Regression
- Evaluating accuracy and a classification report

This is a standard educational dataset and a learning example, not a production application.
