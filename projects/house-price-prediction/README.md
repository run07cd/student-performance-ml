# House Price Prediction

A basic regression project that demonstrates how a model can estimate a numeric value from housing features.

## Run it

From the repository root:

```bash
pip install -r requirements.txt
python projects/house-price-prediction/house_price_prediction.py
```

## What it demonstrates
- Creating a tabular dataset with Pandas and NumPy
- Training a Random Forest Regressor
- Evaluating predictions using MAE and R²
- Making a prediction for a sample house

**Important limitation:** the dataset is generated artificially for practice. Predictions are not real property valuations and should not be used for buying or selling decisions.
